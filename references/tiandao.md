# 天机道 — 紫微斗数命理

> 倪海厦天纪之天机道部分，涵盖紫微斗数、面相、手相、六壬占卜。仅供课程学习参考。

### 算命方法
- 铁板神算（核对六亲比较好）
- 子平法
- **紫微斗数**（最精妙、易学难精通）

- **南斗星**：天府、太阴、天梁、天相、七杀、破军、贪狼

擎羊、陀罗、火星、铃星、天空、地劫

### 四化星深度规则

| 四化 | 入命宫 | 入官禄宫 | 入财帛宫 | 入夫妻宫 | 入其他宫 |
|------|--------|----------|----------|----------|----------|

### 副星
- **文曲星**：才艺、博学、斯文
- **文昌星**：科甲（读书考试）
- **天魁、天钺**：科甲
- **红鸾、天喜**：桃花，男命红鸾招美妻，女命红鸾有贵夫
- **左辅、右弼**：辅助紫微星
- **三台、八座**：辅助天府
- **禄存星**：同化禄
- **天马星**：到外地发展或外调，逢武官星主贵
- **天刑星**：是非、官司、刑尅

### 日期流年规则
- 一年有24个节气，每个节气主两个星期
- 批大限：未来十年无大运，大限在前一年
- 十年大运为主，小流年（看本宫和对宫）为辅
- 流年文昌/化科 = 金榜题名
- 流年遇到化忌 = 诸事不顺
- 润月生人以下个月为论
- 子时生人：11点-12点为晚子时，12点-1点为早子时
- 春分、夏至、秋分、冬至前一日为 **离日**
- 立春、立夏、立秋、立冬前一日为 **决日**
- 这8天人气最弱，诸事不吉

## 深度诊断：十二宫诊断规则

### 命宫
- 空宫 = 看对宫迁移宫
- 单星独守主孤独（尤其左辅右弼+三台八座）
- 杀星坐命 + 早年易夭折（破军廉贞）
- 天相入命女命最佳

### 兄弟宫
- 武曲平+天相庙+地空庙 = 兄弟姐妹助力大
- 化忌代表兄弟夭折
- 凶星云集（廉贪空劫）= 无兄弟或兄弟夭折
- 眉毛很浓、宽厚 = 无兄弟之人

### 夫妻宫
- 武曲庙旺在戌宫：夫妻同行业
- 廉贞陷+贪狼陷：酒色财星、婚姻差
- 廉贞+七杀（半路埋尸）、破军（水中做塚）、贪狼（夭折）
- 太阳陷：丈夫年长7岁以上或二婚夫
- 天喜红鸾在夫妻宫：自己爱且享受
- 紫微在夫妻宫：伴侣优秀
- 太阴化忌：婆媳不和
- 巨日格：女人偏房命
- 廉贞破军入宫：非生离即死别
- 廉贞化忌：桃花的是非，过忌成婚最好

### 子女宫
- 代表儿子的星数：紫微1、天相1、贪狼1、太阳1、天府1、武曲1、天同1、破军2、文昌1、廉贞2、七杀2
- 化忌入子女宫 = 无子
- 空宫（看对宫）+ 对宫化忌 = 无子
- 子女宫 + 化禄 = 贵子
- 红鸾天喜在子女宫 = 有子后婚

### 财帛宫
- 破军：流浪走天下
- 廉贞破军：不可能做生意当老板
- 天钺+文曲+化科：专业技术专长
- 财星+化权 = 自己做老板
- 化忌 = 不能自己做生意

### 疾厄宫（疾病对应）

化忌对应脏腑：子=胆、丑=肝、寅=肺、卯=大肠、辰=胃、巳=脾、午=心、未=小肠、申=膀胱、酉=肾、戌=心包、亥=三焦

**口诀**：肺寅大卯胃辰宫，脾巳心午小未中，申胱酉肾心包戌，亥焦子胆丑肝通

- 七杀独坐 + 在午 = 心脏问题
- 六杀星落陷 + 入疾厄 = 凶
- 六杀星单星独守 = 死限

### 交友宫
- 天机平和、天马 = 为朋友奔波
- 财星吉星 = 合伙大利
- 六杀星或化忌巨门 = 合伙变仇人
- 天钺天魁 = 朋友中有贵人
- 化忌守 = 不会事人

### 田宅宫
- 化忌 = 破祖业
- 太阳陷 = 房子有火灾
- 化忌 + 破祖业面相：鼻孔很大外露

### 福德宫
- 化忌入福德 = 一辈子不顺
- 武曲旺+七杀庙 = 男人个性刚强
- 破军陷+廉贞平（命宫）= 横祸孤独
- 破军在福德或夫妻 = 对婚姻不好

### 父母宫
- 天同 = 感情好；巨门 = 口舌是非
- 武官星入父母宫 = 父亲从武职
- 天魁旺+太阳旺 = 旺父母（孝顺）
- 破军廉贞+杀星 = 父母离散
- 化禄 = 祖上有产业

## 杀星组合效应

- 羊陀夹杀（羊陀在两侧夹命宫）= 容易被影响、犯小人
- 火铃夹 = 爆发力强但风险
- 空劫夹 = 破耗
- 七杀+破军+贪狼三方会 = 刚愎自用、被人利用
- 武曲+七杀（同宫）= 孤独格
- 廉贞+破军（卯酉宫）= 水中做塚
- 廉贞+七杀（未宫）庙旺 = 富人
- 廉贞陷+贪狼陷入命 = 自杀格
- 武曲陷+七杀陷 = 兵阵死亡
- 火星+贪狼 = 火贪格，武贵

## 命盘综合判断法（九步法）

**第一步**：看总格，有没有夹贵/夹权/夹财格局

**第二步**：看命宫 → 三方四正
1. 命宫有什么星
2. 迁移宫（外在/外地）
3. 财帛宫（赚钱方式）
4. 官禄宫（事业方向）

**第三步**：看四化（科权禄忌）

**第四步**：看命宫左右（父母宫+兄弟宫）

**第五步**：看子女宫（单星独守杀=无子）

**第六步**：看大限

**第七步**：断亮度（庙/旺/利/陷）

**第八步**：看杀星组合

**第九步**：综合判断（吉凶+阳宅化解）

## 面相要诀

- 气色枯焦 = 已经发生；气色枯黄 = 刚发生两星期；暗黑色 = 近期将发生
- 黄润 = 喜事；黑暗如灰 = 劫杀；枯萎/青蓝 = 死色
- 额头天庭饱满、山林鼓起 = 祖业雄厚
- 男人手软如棉大福；女人手见筋见骨旺夫
- 眉毛粗 = 独子；眉毛断 = 兄弟姐妹受创
- 眼睛一大一小不在水平线 = 庶出或被领养
- 印堂枯白 = 戴丧；印堂泛红 = 官运进行中；印堂泛黑 = 坐牢
- 天仓地库陷 = 一世辛劳

## 阳宅基础（天机道提及的阳宅要诀）

- 夫妻死别：厕所在房子中间（死于心脏病）；西北角是厨房（刀象）
- 无子宅：正东是客厅或餐厅（缺东宫）
- 凶宅：一般3成灾，3个月或3年
- 主卧在西北角可化解；床不能摆在分经
- 阳宅西北角是厕所：缺夫位
- 读书：书桌朝向化科所在宫位
- 做生意：书桌朝向化禄/贪狼/禄存所在宫位

## 手相要诀

- 手掌明堂要平广，凹下去最吉
- 天柱纹贯穿全掌到中指 = 发科甲
- 手纹细清秀 = 心性正；手纹多横纹多 = 不吉
- 手纹透到手背 = 破祖业
- 人瘦掌肥 = 小气；人胖掌瘦 = 无财
- 小指下方坤宫主夫妻

## 六壬占卜要诀

只需知道农历月、日、时，取食指、中指、无名指推算：

| 位置 | 卦名 | 应期 |
|------|------|------|
| 食指根部 | 大安 | 一个礼拜 |
| 食指顶部 | 流连 | 事情停滞、此行不利 |
| 中指顶部 | 速喜 | 立竿见影 |
| 无名指顶部 | 赤口 | 有第三者介入 |
| 无名指根部 | 小吉 | 两个礼拜后 |
| 中指根部 | 空亡 | 凶 |

空亡=凶；流连=停止不前；赤口=是非第三者介入；速喜=立竿见影；小吉=两周后见结果；大安=一周后见结果
