# 地脉道 — 阳宅风水64局

> 倪海厦天纪之地脉道部分，以易经64卦对应阳宅64局，涵盖房间方位吉凶、厨房厕所客厅布局、夫妻子嗣风水。仅供课程学习参考。

## 核心原则

- **象（名=位）**：厨房（刀象）；客厅（如客）；卫生间（是非、口舌、官司）
- **客厅放在坤位最好**
- 阳宅位置改变一般一个季度转运（三个月）
- **名=位**：让对应的人住在对应的位置 → 家和
- **位=名**：用位置对应的人的名字做事 → 万事兴

## 64局详解（按课程顺序）

### 1. 乾为天 — 父亲住西北角
父亲占正位，大吉：
- 做官：平步青云，心想事成，容易越级晋升
- 商人：财多禄丰，成就不可限量
- 父亲：对家人有责任心，是好丈夫

### 2. 坤为地 — 母亲住西南角
- 婚姻主破散、孤军奋战
- 对事业很好：官家掌权、商人赚钱易如反掌、女强人型
- 一直居住不会二次婚姻
- 经商用母亲名字做负责人对公司大利
- **女子未婚或已婚住西南角=孤独**
- 独居不利：会孤僻到老，无子女愿居身侧

### 3. 水雷屯 — 二儿子住长子位置（正东方）
条件：两个儿子同住正东方卧房，长子已婚或本人已婚
- 比长子早婚，比同时生人早两年婚
- 事业、才智均超越长子
- 肖狗或狄姓之人主夭折，逢狗年加凶
- 肖牛人必任妻摆布，背离家庭

### 4. 山水蒙 — 三儿子住二子位置（正北方）
条件：三个儿子同住家中且均未婚
- 较次子早婚，较长子晚婚；比同时生人早七年
- 以蒙骗之法欺骗家人，惟利是图
- 本身愚昧，不知进退
- 性刚，不听兄长之言
- 喜欢赌博，求财遇险
- **一般正北卧室不住人，可放祖先牌位**

### 5. 水天需 — 长子未婚住父亲位置（西北角）
- 智慧成长太快，顾家
- 个性刚烈不受建言
- 婚事延后7年或不婚或娶二婚妻
- 事业大成，年少居权位

### 6. 天水讼 — 父亲住二子位置（正北方）
- 官司不断，好讼之徒（对律师法官吉）
- 官人居此升官慢五年
- 商人财禄不进
- 有贪念易行险
- 婚姻主破，诉讼离婚

### 7. 地水师 — 母亲住二子位置（正北方）
- 泼妇骂街，女人性刚
- 对婚事必凶，有妻殴夫之象
- 独来独往，胆大过人
- 从商主破婚得财
- 利肖马、虎、羊，官运亨通但婚凶

### 8. 水地比 — 长子未婚住母亲位置（西南角）
- 任劳任怨
- 婚姻延后三年，娶女必长三岁或二婚妻
- 辅佐之才，无法任主管或自己做老板

### 9. 风天小畜 — 未婚长女住父亲位置（西北角）
- 重事业不重婚姻
- 女代父职，能力强过男人
- 事业企图心强，早年为老板
- 大利肖马、肖羊
- 婚姻中丈夫无力助之

### 10. 天泽履 — 父亲住三女儿位置（正西）
- 事业进退两难，靠女人决定解之
- 官运停滞不前
- 妻能力强过自己，有外娶妾行为，主婚姻凶

### 11. 地天泰 — 母亲住父亲位置（西北角）
**夫妻同住最吉（结婚当晚住最好）**：
- 夫妻感情非常好，一世夫妻白首到老
- 进退有据，心想事成
- 健康平安到老，一生无大病

### 12. 天地否 — 父亲住母亲位置（西南角）
- 诸事不顺
- 升迁不成
- 妻盛夫衰，主婚事凶
- 得女
- 个性刚强得罪人

### 13. 天火同人 — 父亲住二女儿位置（正南）
- **发科甲**：父亲住正南卧房考试金榜题名（睡觉脚朝文昌/文曲/天钺/天魁/化科所在方位）
- 财禄平稳
- 文官或武官升迁
- 夫妻同住正南：主妻有暗伤（解决方法：妻子仍睡西北角）

### 14. 火天大有 — 次女住父位（西北角）
条件：自己未婚、姐姐未嫁
- 个性阳刚盛于男人
- 未婚先得子，主二子
- 婚姻提前三年
- 属狗的主大吉大利

### 15. 地山谦 — 母亲住东北角
**65岁以前住不吉**：
- 65岁前主夫妻感情退化
- 所思不成、头痛、劳多成疾
- 住10年以上眼睛会目带凶光

### 16. 雷地豫 — 长子住西南角
- 有母性、喜欢家事
- 娶二婚妻或年长妻
- 婚姻晚一年
- 事业做佐才

### 17. 泽雷随 — 三女儿住正东方
条件：长女和儿女均未婚
- 女身男态
- 女同性恋
- 一心为事业
- 婚姻能成，必嫁富夫，早四年

### 18. 山风蠱 — 少男居西南角
- 图利心大
- 行蠱惑之道，破坏人情
- 发科甲，读书考试必超人一等
- 早婚，提前4年

### 19. 地泽临 — 母亲住正西
- 父业受困，乃因母也
- 单居之母大材小用
- 夫妻同住，夫不如妻顺遂
- 属虎的母亲主婚事破，但事业力争上游

### 20. 风地观 — 长女住西南角
- 以财禄多少决定是否嫁人
- 主偏房、不婚
- 有婚晚6年，嫁二婚夫且带子
- 有代母之象，母凶

### 21. 火雷噬嗑 — 二女住正东方
- 女孩小时候喜欢咬人
- 唠叨不听
- 婚对象为阴柔之性男人
- 婚延6年
- 财禄官带皆吉
- 属鸡女性逢之必坐吃山空

### 22. 山火贲 — 三子住正南
条件：长子和二子未婚
- 男身女态
- 性静不动
- 身体烫伤较多
- 婚姻不成
- 兴科甲，考试大利

### 23. 山地剥 — 三儿子住西南角
条件：长子和二子未婚
- 破耗家业，伦理丧失
- 性毒暗生
- 婚不成
- 科甲不顺，考试必败
- 身体灾病多——**大凶**

### 24. 地雷复 — 母亲住正东
- 女身男命
- 发武官
- 代夫出征，不让须眉
- 官运利，属虎兔大吉
- 夫妻不合，婚姻凶

### 25. 天雷无妄 — 父亲住正东
- 必从商且吉，但防阴人暗害
- 官人则因利犯险
- 性刚而动求财一心，果自乱阵脚

### 26. 山天大畜 — 三儿子住西北角
条件：长子和二子未婚
- 代父出征
- 性刚财积大
- 婚姻短暂，不成三个月，婚提前两年
- 公职不利

### 27. 山雷颐 — 三儿子住正东
条件：长子和二子未婚
- 早发之象
- 健康平安
- 婚提前5年
- 同父异母之象

### 28. 泽风大过 — 三女住东南角
条件：长女和二女未婚
- 早婚三年，嫁夫长十岁以上
- 身入豪门世家
- 性情很刚，任性而为
- 夫妻年纪接近主凶

### 29. 坎为水 — 二子居正北
条件：长子未婚
- 以行险为乐
- 属牛虎则吉
- 属老鼠暗中生害
- 婚延后2年
- 常有牢狱官司
- **二儿子最好住正南卧房，吉**

### 30. 离为火 — 二女居正南
条件：长女未嫁
- 心在迁移海外
- 正红鸾
- 明理而不惧
- 破财不守
- 科甲名列前茅

### 31. 泽山咸 — 三女住东北角
- 婚成于媒妁之言，先成后破
- 对象必为豪门世家
- 婚延一年，单年结婚
- 事业财禄均好，但科甲不兴

### 32. 雷风恒 — 长子住东南角
- 易从不正的宗教
- 智慧会有蒙蔽
- 心生毒害，凶
- 婚姻晚一年
- 官运不佳、商场不顺，科甲旺

### 33. 天山遁 — 父亲住东北角
- 萌生退意
- 夫妻感情退化
- 事业回归原地
- 身体退化，中年得老年病
- **65岁住吉**（65岁前不吉）

### 34. 雷天大壮 — 长子住西北角（未婚）
- 性刚强，一家之主，越居父位
- 家庭责任感重
- 不婚为吉；如婚配属兔猴羊，不出三个月婚破
- 事业独立自主，自由业利
- **不要住超过三个月以上**

### 35. 火地晋 — 二女住西南角
- 性柔如慈母
- 婚晚，40岁以后
- 偏房或二房
- 财禄节省
- 婚对象属鸡大吉

### 36. 地火明夷 — 母亲住正南
- 性刚烈如火
- 必有隐疾难言
- 破财诸事不顺
- 易受小人言，招人暗害
- 唯属虎者可平安度过
- 见血光必凶

### 37. 风火家人 — 长女住正南
- 官运不前
- 科甲高中
- 婚姻延后五年
- 家人和睦
- 妇人病多

## 化解速查表

| 问题 | 化解方法 |
|------|----------|
| 西北角是厨房 | 死先生（刀象），移到其他方位 |
| 西南角是厨房 | 死太太 |
| 正东是厨房 | 主长子夭折（改正东为卧房） |
| 房子中间是厕所 | 主闷、心脏病 |
| 西北角是客厅 | 夫妻生离 |
| 正东是客厅 | 生不到儿子或儿子如客人 |
| 无子宅 | 正东缺宫；床头靠北或西为吉 |
| 两代人同住 | 年轻夫妻住西北角坤卦，父母住东北角艮卦 |
| 母亲独居 | 西北角 → 母代父职（辛苦） |
| 妻子再婚 | 带子女一起住西南角；单身住东南角 |
| 西北角缺位 | 得不到丈夫的助力 |
| 厨房最佳方位 | 正北方或正西方 |

## 客厅方位吉凶
- **坤位（西南角）**：最好
- 正东：生不到儿子；儿子如客人
- 西北角：丈夫把家当旅馆，夫妻生离

## 厨房方位吉凶
- 最佳：正北方、正西方
- 西北角：刀象，死先生
- 西南角：死太太
- 正东：长子夭折

## 厕所方位
- 房子中间：闷，主心脏病
- 西北角：缺夫位
